## 1.Vim

### 1.1 Vim文本对象

Vim 里有一套非常好用的操作方式：

```text
操作符 + i/a + 对象
```

其中：

- `i = inner`：内部，不包含边界符号、括号、引号
- `a = around`：周围，包含边界符号，有时也会包含后面的空格

常用操作符：

| 操作符 | 含义                               |
| ------ | ---------------------------------- |
| `d`    | delete，删除                       |
| `c`    | change，修改，删完直接进入插入模式 |
| `y`    | yank，复制                         |
| `v`    | visual，选中，进入可视模式         |

光标只要落在对象内部任意位置，不需要移动到开头或者结尾，直接执行命令即可。

---

**1. 单词类**

| 命令 | 含义                                               |
| ---- | -------------------------------------------------- |
| `iw` | inner word，单词内部，不包含后面的空格             |
| `aw` | a word，整个单词，通常包含后面的空格               |
| `iW` | inner WORD，以空格分割的大单词，标点算单词的一部分 |
| `aW` | a WORD，大单词 + 后面空格                          |

常用示例：

```vim
diw
```

删除光标所在单词，不删除周围空格。

```vim
daw
```

删除整个单词，通常连后面的空格一起删除。

```vim
ciw
```

修改当前单词，删掉以后直接进入插入模式。

例如：

```cpp
int number = 10;
```

光标放在 `number` 任意位置，执行：

```vim
ciw
```

然后输入：

```text
value
```

得到：

```cpp
int value = 10;
```

---

**2. 括号 / 引号**

这部分写 C / C++ 时非常常用。

| 命令        | 含义                           |
| ----------- | ------------------------------ |
| `i(` / `ib` | 小括号 `()` 内部，不包括括号   |
| `a(` / `ab` | 小括号全部，包括括号本身       |
| `i{` / `iB` | 大括号 `{}` 内部，不包括大括号 |
| `a{` / `aB` | 大括号全部，包括大括号         |
| `i[`        | 中括号 `[]` 内部               |
| `a[`        | 中括号全部，包括 `[]`          |
| `i"`        | 双引号内部，不包含引号         |
| `a"`        | 双引号全部，包含引号           |
| `i'`        | 单引号内部                     |
| `a'`        | 单引号全部，包含单引号         |
| `i<`        | 尖括号 `<>` 内部               |
| `a<`        | 尖括号全部                     |

例如：

```cpp
func(123 + 456);
```

光标在括号中间任意位置：

```vim
ci(
```

删除括号里面：

```text
123 + 456
```

但是保留括号，然后直接进入插入模式。

```vim
da(
```

删除整个：

```text
(123 + 456)
```

连括号一起删除。

```vim
yi(
```

复制括号里面的内容。

再例如：

```cpp
std::string s = "hello world";
```

光标放在字符串内部：

```vim
ci"
```

删除：

```text
hello world
```

但是保留双引号，然后可以直接输入新字符串。

---

**3. 段落、句子**

| 命令 | 含义                                |
| ---- | ----------------------------------- |
| `ip` | inner paragraph，当前段落           |
| `ap` | a paragraph，整个段落，包括周围空行 |
| `is` | inner sentence，句子内部            |
| `as` | a sentence，完整句子                |

写代码比较常用：

```vim
vip
```

选中当前段落。

```vim
dip
```

删除当前段落。

```vim
cip
```

修改当前段落。

---

**4. 常用组合**

```vim
ci(     " 修改括号里面内容
ca{     " 修改整个大括号，包括 {}
di"     " 删除引号内部文字
ya{     " 复制整个大括号，包括 {}
vip     " 选中整个段落
vab     " 选中整个小括号，包括 ()
```

---

**5. 和 Commentary 插件配合**

如果安装了支持 `gc` 的注释插件，例如 Commentary，可以和 Vim 文本对象组合使用。

```vim
gcc
```

注释 / 取消注释当前行。

```vim
gcip
```

可以理解为：

```text
gc + ip
```

也就是对当前段落执行注释操作。

```vim
gcib
```

对小括号内部内容执行注释操作。

---

**6. 快速记忆**

```text
i 拿里面
a 拿全套

c 改
d 删
y 复制
v 选中
```

例如：

```vim
ci"
```

可以拆成：

```text
c   change
i   inner
"   双引号对象
```

意思就是：

> 修改双引号内部内容。

而：

```vim
da(
```

可以拆成：

```text
d   delete
a   around
(   小括号对象
```

意思就是：

> 删除整个小括号，包括括号本身。

**7. C++ 实战练习**

准备下面这段代码：

```cpp
#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int main()
{
    cout << "hello world" << '\n';

    int ans = add(10, 20);

    return 0;
}
```

光标放在：

```cpp
int a, int b
```

里面，执行：

```vim
ci(
```

观察效果。

光标放在：

```text
hello world
```

里面，执行：

```vim
ci"
```

直接修改字符串。

光标放在函数体里面，执行：

```vim
ya{
```

复制整个大括号代码块。

**最值得先记住的命令**

```vim
ciw     修改当前单词
diw     删除当前单词
ci"     修改字符串内容
ci(     修改括号内容

da(     删除整个括号
```

### **1.2Vim 多窗口（分屏）**

Vim 中常见的多窗口操作主要分为两类：

- **水平分屏（上下）**：`split`，简写为 `sp`
- **垂直分屏（左右）**：`vsplit`，简写为 `vsp`

下面涉及 `:sp`、`:vsp` 等命令时，都需要先按 `Esc` 回到普通模式，再输入 `:` 执行。

---

**1、创建分屏**

| 命令            | 效果                                 |
| --------------- | ------------------------------------ |
| `:sp`           | 水平分屏，上下两个窗口打开同一个文件 |
| `:sp main.cpp`  | 水平分屏，新窗口打开 `main.cpp`      |
| `:vsp`          | 垂直分屏，左右两个窗口打开同一个文件 |
| `:vsp main.cpp` | 垂直分屏，新窗口打开 `main.cpp`      |

也可以直接使用普通模式下的快捷键：

~~~text
Ctrl-w s    等价于 :sp，水平分屏
Ctrl-w v    等价于 :vsp，垂直分屏
~~~

---

**2、窗口之间切换（最重要）**

先按 `Ctrl-w`，松开后，再按 `h / j / k / l`：

~~~text
Ctrl-w h    跳到左边窗口
Ctrl-w l    跳到右边窗口
Ctrl-w j    跳到下边窗口
Ctrl-w k    跳到上边窗口
~~~

方向和 Vim 原生移动键完全一致：

~~~text
h ←
j ↓
k ↑
l →
~~~

因此很好记：

~~~text
Ctrl-w + 方向键
~~~

例如想切换到右边窗口：

~~~text
Ctrl-w l
~~~

> `Ctrl-w` 一般是先按住 `Ctrl` 按一下 `w`，然后松开，再按 `h / j / k / l`。

---

**3、关闭窗口**

| 命令       | 作用                                           |
| ---------- | ---------------------------------------------- |
| `:q`       | 关闭当前窗口；如果只剩最后一个窗口，则退出 Vim |
| `:qall`    | 关闭全部窗口并退出 Vim                         |
| `:wqall`   | 保存全部文件并退出 Vim                         |
| `Ctrl-w q` | 关闭当前窗口                                   |
| `:only`    | 只保留当前窗口，关闭其他所有窗口               |

其中非常常用的是：

~~~vim
:only
~~~

当分屏太多、界面比较乱时，可以直接只保留当前正在使用的窗口。

---

**4、调整窗口大小**

普通模式下可以使用：

~~~text
Ctrl-w +    增加当前窗口高度
Ctrl-w -    减小当前窗口高度

Ctrl-w >    加宽当前窗口
Ctrl-w <    收窄当前窗口

Ctrl-w =    所有窗口平均分配大小
~~~

例如分成左右两个窗口后，如果右边窗口太窄，可以切换到右边窗口，然后：

~~~text
Ctrl-w >
~~~

不断增加它的宽度。

---

**5、移动窗口位置**

除了切换窗口之外，还可以直接改变当前窗口的位置：

~~~text
Ctrl-w H    当前窗口移动到最左边
Ctrl-w L    当前窗口移动到最右边
Ctrl-w J    当前窗口移动到最下面
Ctrl-w K    当前窗口移动到最上面
~~~

这里需要注意：

~~~text
h j k l
~~~

是**小写**，表示切换到对应方向的窗口。

而：

~~~text
H J K L
~~~

是**大写**，表示把当前窗口移动到对应位置。

例如：

~~~text
Ctrl-w h
~~~

表示切换到左边窗口。

而：

~~~text
Ctrl-w H
~~~

表示直接把当前窗口移动到最左边。

---

**6、标签页**

标签页和分屏并不是同一个概念：

~~~text
分屏   = 一个页面被切割成多个窗口
标签页 = 多个相对独立的页面
~~~

常用标签页命令：

~~~vim
:tabe file.cpp
~~~

新建一个标签页并打开 `file.cpp`。

切换标签：

~~~text
gt     下一个标签
gT     上一个标签
~~~

关闭当前标签：

~~~vim
:tabc
~~~

---

**📌 高频实战示例**

打开 `main.cpp` 后，想在右边同时查看头文件 `test.h`：

~~~vim
:vsp test.h
~~~

效果类似：

~~~text
┌────────────────────┬────────────────────┐
│                    │                    │
│     main.cpp       │      test.h        │
│                    │                    │
└────────────────────┴────────────────────┘
~~~

在两个窗口之间切换：

~~~text
Ctrl-w h    切到左边
Ctrl-w l    切到右边
~~~

---

分屏太多时，只保留当前窗口：

~~~vim
:only
~~~

---

Vim 8+ / Neovim 还可以直接在分屏中打开终端。

例如：

~~~vim
:sp | terminal
~~~

可以实现上面写代码、下面运行程序：

~~~text
┌─────────────────────────────────────────┐
│                                         │
│                main.cpp                 │
│                                         │
├─────────────────────────────────────────┤
│ $ g++ main.cpp -o main && ./main        │
│                                         │
└─────────────────────────────────────────┘
~~~

这样可以直接在 Vim 中完成：

~~~bash
g++ main.cpp -o main && ./main
~~~

不用频繁退出 Vim。

---

**⚠️ 小坑提醒**

`Ctrl-w` 相关操作一般不要一直把所有按键同时按住。

推荐操作方式：

~~~text
按住 Ctrl
↓
按 w
↓
松开
↓
按 h / j / k / l
~~~

---

所有分屏窗口共享 Vim 的寄存器，因此在一个窗口复制的内容，可以直接在另一个窗口粘贴。

例如：

~~~text
yy
~~~

复制当前行，然后切换窗口：

~~~text
Ctrl-w l
~~~

再：

~~~text
p
~~~

即可粘贴。

---

不同窗口既可以打开**不同文件**：

~~~vim
:vsp test.h
~~~

也可以打开**同一个文件**。

如果两个窗口打开的是同一个文件，对其中一个窗口中的内容进行修改，另一个窗口也会同步看到修改结果。

---

**最后记住最常用的一组即可：**

~~~text
:sp          上下分屏
:vsp         左右分屏

Ctrl-w h     左
Ctrl-w j     下
Ctrl-w k     上
Ctrl-w l     右

Ctrl-w =     平均窗口大小
Ctrl-w q     关闭当前窗口
:only        只保留当前窗口
~~~

## 2 Makefile

目标文件：依赖文件

编译命令  
> 前面必须是 `Tab` 缩进，不能用空格

```bash
make        # 编译生成 ./main
./main      # 运行程序
make clean  # 删除可执行文件
```

```makefile
main: reply.o main.o
	g++ reply.o main.o -o main

reply.o: reply.cpp
	g++ -c reply.cpp -o reply.o

main.o: main.cpp
	g++ -c main.cpp -o main.o
```

Makefile 的简化规则：

变量定义：

```makefile
变量名=字符串
```

变量使用：

```makefile
$(变量名)
```

例如：

```makefile
TARGET=main
OBJS=reply.o main.o

# 伪目标，必须加上，防止目录中出现名为 clean 的文件导致失效
# 表示不生成目标文件
.PHONY: clean

$(TARGET): $(OBJS)
	g++ $(OBJS) -o $(TARGET)

reply.o: reply.cpp
	g++ -c reply.cpp -o reply.o

main.o: main.cpp
	g++ -c main.cpp -o main.o

clean:
	rm -f $(TARGET) $(OBJS)
```

```makefile
# 安装：复制可执行文件到 bin
install:
        cp ./main  /usr/local/bin/mainTest
# 卸载：删除安装的文件
uninstall:
         rm /usr/local/bin/mainTest
```

```bash
sudo make install #安装到 /usr/local/bin，需要root,安装后可直接mainTest相当于./main运行程序
sudo make install #安装到 /usr/local/bin，需要root
```
