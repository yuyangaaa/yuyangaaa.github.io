# 1.Vim

## 1.1 Vim文本对象

Vim 里有一套非常好用的操作方式：

```text
操作符 + i/a + 对象
```

其中：

- `i = inner`：内部，不包含边界符号、括号、引号
- `a = around`：周围，包含边界符号，有时也会包含后面的空格

常用操作符：

| 操作符 | 含义                               |
| ------ | ---------------------------------- |
| `d`    | delete，删除                       |
| `c`    | change，修改，删完直接进入插入模式 |
| `y`    | yank，复制                         |
| `v`    | visual，选中，进入可视模式         |

光标只要落在对象内部任意位置，不需要移动到开头或者结尾，直接执行命令即可。

---

**1. 单词类**

| 命令 | 含义                                               |
| ---- | -------------------------------------------------- |
| `iw` | inner word，单词内部，不包含后面的空格             |
| `aw` | a word，整个单词，通常包含后面的空格               |
| `iW` | inner WORD，以空格分割的大单词，标点算单词的一部分 |
| `aW` | a WORD，大单词 + 后面空格                          |

常用示例：

```vim
diw
```

删除光标所在单词，不删除周围空格。

```vim
daw
```

删除整个单词，通常连后面的空格一起删除。

```vim
ciw
```

修改当前单词，删掉以后直接进入插入模式。

例如：

```cpp
int number = 10;
```

光标放在 `number` 任意位置，执行：

```vim
ciw
```

然后输入：

```text
value
```

得到：

```cpp
int value = 10;
```

---

**2. 括号 / 引号**

这部分写 C / C++ 时非常常用。

| 命令        | 含义                           |
| ----------- | ------------------------------ |
| `i(` / `ib` | 小括号 `()` 内部，不包括括号   |
| `a(` / `ab` | 小括号全部，包括括号本身       |
| `i{` / `iB` | 大括号 `{}` 内部，不包括大括号 |
| `a{` / `aB` | 大括号全部，包括大括号         |
| `i[`        | 中括号 `[]` 内部               |
| `a[`        | 中括号全部，包括 `[]`          |
| `i"`        | 双引号内部，不包含引号         |
| `a"`        | 双引号全部，包含引号           |
| `i'`        | 单引号内部                     |
| `a'`        | 单引号全部，包含单引号         |
| `i<`        | 尖括号 `<>` 内部               |
| `a<`        | 尖括号全部                     |

例如：

```cpp
func(123 + 456);
```

光标在括号中间任意位置：

```vim
ci(
```

删除括号里面：

```text
123 + 456
```

但是保留括号，然后直接进入插入模式。

```vim
da(
```

删除整个：

```text
(123 + 456)
```

连括号一起删除。

```vim
yi(
```

复制括号里面的内容。

再例如：

```cpp
std::string s = "hello world";
```

光标放在字符串内部：

```vim
ci"
```

删除：

```text
hello world
```

但是保留双引号，然后可以直接输入新字符串。

---

**3. 段落、句子**

| 命令 | 含义                                |
| ---- | ----------------------------------- |
| `ip` | inner paragraph，当前段落           |
| `ap` | a paragraph，整个段落，包括周围空行 |
| `is` | inner sentence，句子内部            |
| `as` | a sentence，完整句子                |

写代码比较常用：

```vim
vip
```

选中当前段落。

```vim
dip
```

删除当前段落。

```vim
cip
```

修改当前段落。

---

**4. 常用组合**

```vim
ci(     " 修改括号里面内容
ca{     " 修改整个大括号，包括 {}
di"     " 删除引号内部文字
ya{     " 复制整个大括号，包括 {}
vip     " 选中整个段落
vab     " 选中整个小括号，包括 ()
```

---

**5. 和 Commentary 插件配合**

如果安装了支持 `gc` 的注释插件，例如 Commentary，可以和 Vim 文本对象组合使用。

```vim
gcc
```

注释 / 取消注释当前行。

```vim
gcip
```

可以理解为：

```text
gc + ip
```

也就是对当前段落执行注释操作。

```vim
gcib
```

对小括号内部内容执行注释操作。

---

**6. 快速记忆**

```text
i 拿里面
a 拿全套

c 改
d 删
y 复制
v 选中
```

例如：

```vim
ci"
```

可以拆成：

```text
c   change
i   inner
"   双引号对象
```

意思就是：

> 修改双引号内部内容。

而：

```vim
da(
```

可以拆成：

```text
d   delete
a   around
(   小括号对象
```

意思就是：

> 删除整个小括号，包括括号本身。

**7. C++ 实战练习**

准备下面这段代码：

```cpp
#include <iostream>
using namespace std;

int add(int a, int b)
{
    return a + b;
}

int main()
{
    cout << "hello world" << '\n';

    int ans = add(10, 20);

    return 0;
}
```

光标放在：

```cpp
int a, int b
```

里面，执行：

```vim
ci(
```

观察效果。

光标放在：

```text
hello world
```

里面，执行：

```vim
ci"
```

直接修改字符串。

光标放在函数体里面，执行：

```vim
ya{
```

复制整个大括号代码块。

**最值得先记住的命令**

```vim
ciw     修改当前单词
diw     删除当前单词
ci"     修改字符串内容
ci(     修改括号内容
ci{     修改大括号内容
da(     删除整个括号
ya{     复制整个大括号代码块
vip     选中当前段落
gcc     注释当前行
gcip    注释当前段落
```
